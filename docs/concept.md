# Lantern コンセプト

## 一言で

誰かに見せるためではなく、誰かの灯りを見るための SNS。

## 目的

Lantern は、短い思考や気配を安心して置ける場所を目指します。投稿者の人気、フォロワー数、反応数の競争ではなく、匿名の言葉そのものと、そこへ向けられる静かな反応を中心にします。

## プロダクト原則

- 匿名で投稿できる
- フォロワー機能を持たない
- 公開された人気ランキングを作らない
- 反応は「いいね」ではなく「灯す」と表現する
- 投稿は短く、読み流しやすくする
- 初期画面は新着フィードを中心にする

## MVP

MVP では、次の体験を成立させます。

1. ユーザーが username/password で登録・ログインする
2. ログインユーザーが短い匿名投稿を作成する
3. 投稿が新着順で表示される
4. ログインユーザーが投稿を灯せる

## MVP でやらないこと

- フォロー/フォロワー
- 公開ランキング
- リポスト
- DM
- 画像投稿
- 複雑なレコメンド

## 言葉づかい

- 投稿への反応は「灯す」
- 反応済み状態は「灯した」
- 投稿一覧は「新着」
- ユーザー識別子は UI 上では原則表示しない
